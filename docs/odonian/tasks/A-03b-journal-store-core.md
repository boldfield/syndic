## Goal

The store API over the A-03a schema for everything except candidates, verdicts and blocks. It carries the durable-intent and recovery invariants. No engine logic.

## Design reference

`docs/design/v3-delta-api-alpha.md` section 5, especially the last paragraph (durable intent precedes dispatch; recovery marks unknown and never re-sends). `docs/design/v2-candidate.md` sections 3 and 7 (engine-computed hashes, sequence, epochs).

## Deliverables

In package `internal/journal`, a `Store` constructed from the `*DB` that A-03a's `Open` returns. Every method runs in one transaction. IDs are generated by the store (random, URL-safe). Do not change the migrations; if the schema cannot support a method below, stop and report.

- `CreateRun(manifest json.RawMessage) (runID, manifestHash, error)`: the hash is the hex SHA-256 of the manifest bytes exactly as given, computed here, never supplied by the caller. Rejects input that is not valid JSON.
- `CreateTurn(runID, mode, deadline) (turnID, error)`.
- `SetTurnTerminal(turnID, state) error`: rejects if the turn already has a terminal state.
- `AppendMessage(turnID, phase, sender, recipients, content, parents) (msgID, sha256, byteLen, error)`: sequence is assigned by the store, increasing per turn; hash and length are computed by the store from the content bytes.
- `BeginAttempt(turnID, participant, phase, epoch, deadline, repairOf) (attemptID, error)`: the row is committed in state `pending` before the function returns. This is the durable-intent record. `repairOf` is empty or an existing attempt id.
- `CompleteAttempt(attemptID, rawScrubbed, scrubCount, identity, status, nativeFinish, transportStatus) error`: sets state `completed`. Rejects unless the attempt is `pending`.
- `QuarantineLateOutput(attemptID, rawScrubbed, scrubCount, identity, status, nativeFinish, transportStatus) error`: same write as `CompleteAttempt` plus `quarantined` true. It touches no other table.
- `SetCancellation(attemptID, cancellationState) error`.
- `MarkUnknown(attemptID) error`: sets state `unknown`. Rejects unless the attempt is `pending`.
- `RecoverPending() ([]attemptID, error)`: returns attempts in state `pending`. The caller decides what to mark; the store never dispatches anything.
- `AppendEvent(kind string, payload json.RawMessage) error`. No other exported function writes to `events`.
- `GetAttempt(attemptID)` and `GetRun(runID)` returning plain structs, for tests and for A-08.

## Acceptance

- `BeginAttempt` row is visible from a second connection to the same file before `CompleteAttempt` is called.
- `CompleteAttempt` twice on one attempt errors; the first output is unchanged.
- `CompleteAttempt` and `MarkUnknown` each error on an attempt that is not `pending`.
- `AppendMessage` hash equals an independently computed SHA-256 of the content, byte length equals `len(content)`, and two messages in one turn get increasing sequence numbers. Identical content from two senders is accepted as two messages.
- `CreateRun` hash equals an independently computed SHA-256 of the manifest bytes.
- Recovery: begin an attempt, close the database, reopen; `RecoverPending` returns it; after `MarkUnknown` it no longer does.
- `QuarantineLateOutput` leaves the turn's terminal state unchanged.
- `go vet` and lint clean.

## Out of scope

Candidates, verdicts and blocks (A-03c). Schema changes. Scheduling, deadline enforcement, protocol logic, any network.
